# 畫面導覽

控制台是單一視窗。由上到下：標題列 → 專案列 → 工具列 → 摘要列 → 左右分頁 → 狀態列。

## 標題列

| 項目 | 作用 |
|------|------|
| 名稱與版本 | 目前安裝的控制台版號 |
| **開發／需求** | 切換工作台。開發＝編譯與承接任務；需求＝進件、發出 Issue、審查到驗收。需求台左右兩欄中間可拖拉。見 [需求工作台](intake.md) |
| **本次／今日工時** | 從開啟目前專案到現在、以及今天各專案合計的工作時數。滿 8 小時會變黃、滿 10 小時變紅。點擊打開週／月／季／年儀表板與報帳單 |
| **設定** | 外觀、Agent、MCP、工具權限、專案問答。見 [設定](settings.md) |
| **檢查更新** | 查 GitHub Releases 是否有新版 |
| GitHub 帳號 | 已登入時顯示 `@帳號`；企業主機時加上主機名稱 |
| **登出 GitHub** | 登出 GitHub CLI。GitHub 管理的專案之後要重新登入 |
| **離開** | 關閉控制台視窗。工作區必須乾淨、且沒有未發布提交，否則不能離開。本機 Agent 會再問是否一併關閉該應用程式 |

## 專案列

| 項目 | 作用 |
|------|------|
| 專案名稱／路徑 | 尚未選擇時會提示你選目錄 |
| **分支** | 目前 git 分支。點一下可切換或建立新分支 |
| **歷史專案** | 最近開過的目錄（最多 12 個仍存在的路徑） |
| **選擇專案目錄…** | 本機資料夾選擇 |
| **從 GitHub 開啟…** | clone 遠端倉後當作專案開啟 |
| **關閉專案** | 卸下目前工作區。工作區必須乾淨且已發布，否則不能關閉。本機 Agent 會再問是否一併關閉該應用程式 |
| **啟動時還原上次專案** | 下次啟動自動載入 |
| **同時開啟 {後端}** | 載入專案時一併打開 Cursor（或其他你選的 Agent） |

## 工具列

| 按鈕 | 作用 |
|------|------|
| **啟動** | 依啟動順序啟動尚未在線的服務。有 `preStart` 的會先跑腳本，失敗則不啟動該服務 |
| **停止全部** | 停止此工作區控制台管到的服務 |
| **開啟前端** | 開預設前端網址，或「開啟全部 URL」 |
| **UAT 求救** | 填說明／貼截圖，交給 Agent。見 [卡住時怎麼辦](help.md) |
| **建置** | 編譯過期項目／全部服務／全部專案（含測試）／跑測試 |
| **GitHub** | 設定、切換分支、提交、同步、發布、Release、PR 檢查、補齊 CI workflow、Actions 狀態。見 [GitHub](github.md) |
| **部署** | 發佈目標設定與狀態。見 [部署](deploy.md) |
| **文件** | 建立體系、AI 補齊、本機 DocFX 預覽、GitHub Pages。見 [專案文件](docs.md) |
| **環境體檢** | 跳出視窗：dotnet／git／gh／Agent／文件狀態／目前專案服務清單 |

建置「全部專案」會編譯目錄內全部 `.csproj`（含測試），可能要數分鐘，執行前會確認。「跑測試」是一次完整 `dotnet test`（有方案就跑方案），不是 IDE 裡的測試總管。

## 摘要列

一眼看值班狀態，不必翻分頁。

| 顯示 | 意思 |
|------|------|
| 就緒 N / M | 健康檢查通過的服務數／服務總數 |
| **需重編 N** | 點一下切到左側「專案」。黃色＝有過期項目 |
| **MCP 拒絕 N** | 點一下打開右側「MCP 審計」。對帳單，不是警報。政策擋下或未知工具不會變黃；只有工具真的失敗才黃 |
| **我的任務 N** | GitHub 專案登入後出現。點一下切到左側「任務」 |
| **文件 …** | 點一下切到左側「文件」。黃色＝無文件／缺骨架／有待補 |
| **CI …** | GitHub 專案已登入後出現。點一下到 GitHub 看 log。綠＝通過、主色＝進行中。剛推送後失敗才黃；歷史失敗是事實、不亮警報。控制台不能修 CI |
| **PR …** | 目前分支有 PR，或不是 main／master 時出現。綠＝檢查已過可請人審、黃＝未過、主色＝檢查中。點一下看摘要，審查與合併請到 GitHub |
| 堆疊正常／離線… | 值班一句話；與 MCP 工具 `duty_summary` 同一組數字 |
| 分支 · 未提交 · ↑↓ | git 狀態，可點擊切換分支。有未提交時可直接「提交…」 |
| 底部工作訊息 | 正在編譯、啟動等 |

## 左側：服務／專案／文件／任務

連點「服務」「專案」分頁標題可全部展開或收合群組。

### 服務

每一列：線上／離線、名稱、連接埠、操作。

- **開啟** — 瀏覽器開該服務的 `openUrl`
- **啟動／重啟／停止** — 單一服務
- **隨 xxx** — 這個項目掛在另一個行程上（例如 Web 跟 API 同一 process），不要單獨啟動
- **失敗** — 滑鼠停上看啟動錯誤；右側 Log 有完整輸出

沒有服務時：放 `ai-project.json`，或確認 `launchSettings.json` 有 `applicationUrl`。

### 專案

每一列：專案名、類型／語言／上次編譯、狀態徽章、**編譯**。

| 徽章 | 意思 |
|------|------|
| 需重編 | 原始碼比輸出新。滑鼠停在列上看是哪個檔觸發 |
| 未建置 | 還沒編譯過 |
| 最新 | 控制台自己編譯成功且來源沒再改 |
| 編譯中 | 進行中（列會用主色標示） |
| 失敗 | 看右側「建置輸出」，可用編譯求救 |

勾選「只看需重編」可過濾。狀態不對時按「刷新」。`appsettings`、`data/*.json` 通常**不**應觸發需重編。

### 任務

登入 GitHub 後，顯示目前倉庫的開放 Issue。

- **我的任務** — 指派給你的項目。點標題開瀏覽器；按 **請 Agent 協助** 把 Issue 交給後端 Agent
- **未指派** — 沒有負責人的項目，預設可開合。按 **接受** 指派給自己，就會出現在上方

沒有 GitHub 遠端的本機目錄不會要求登入，這個分頁會提示尚未接上 GitHub。

### 文件

列出目前專案 `docs/` 的目錄樹。先選資料夾裡的檔，再在右側編輯。沒有骨架時按「建立體系」；也可「新增文件」。多餘的頁用工具列、檔案列或右側的「刪除」，會先確認再移除本機檔。見 [專案文件](docs.md)。

## 右側：Log／建置／審計／問答／文件

中間的分隔線可拖拉；連點還原左右各半。

### 服務 Log

選左側一個服務後顯示它的輸出。可搜尋、跟隨最新、清空顯示（不清實體檔）、開啟 `.ai_project/logs` 資料夾。線上服務異常時可用 **執行求救**。

### 建置／測試

顯示 `{已完成}/{預計}`。編譯或本機測試失敗時 **編譯求救** 可用。報告也寫在 `.ai_project/build-reports/`。

### MCP 審計

Agent 透過 MCP 呼叫控制台的對帳單（成功或被拒）。尚無紀錄通常表示還沒接 MCP，不是故障。見 [MCP](../agent/mcp.md)。

### 專案問答

在控制台內用本機堆疊事實回答（預設接 Ollama）。**不會**外開 Cursor，也不會鎖住啟動／編譯。需先在設定填模型。見 [卡住時怎麼辦](help.md)。

### 文件

編輯選中的 Markdown。勾選「本頁預覽」只看目前這頁；「網站預覽本頁」才開 DocFX 網站的目前這頁（設定檔則開首頁）。可儲存、AI 補齊本頁。

## 工時儀表板

標題列的工時徽章打開這個視窗。工時從**開啟專案**起算，切換或關閉專案會切開時段，寫入本機 `%LOCALAPPDATA%\AI_Project_Console\work-hours.json`。尚未選擇專案時不計時。同一人用 GitHub 帳號歸檔（`personKey` = `github:帳號`）；還沒登入時先記在本機 Windows 使用者下，登入後會把尚未歸戶的時段併到這個帳號。另一個 GitHub 帳號的時段不會混進來。舊版沒有專案欄位的時段會標成「未掛專案」，儀表板看得到，但不列入報帳單。

| 項目 | 作用 |
|------|------|
| **週／月／季／年** | 切換視圖。週、月列出每一天；季、年只列出有上班的日子，圖表改成各月合計 |
| **儀表板／報帳單** | 儀表板看圖表與作息；報帳單看各專案可報帳時數、已關閉 Issue、開啟或合併的 PR |
| **各專案時數** | 期間內每個專案的合計。點一列只看該專案的圖表；同一 GitHub 倉（`owner/repo`）會併在一起 |
| **上一週／下一週…** | 前後期間。不能翻到未來 |
| **圖表** | 每天（或每月）時數。週／月圖上的虛線是 8 小時。季／年點某月會鑽到該月 |
| **每日時段** | 當天每一段開啟～離開，例如 `09:12–12:40`。跨午夜會拆成兩天 |
| **匯出工時單** | 選一個資料夾，寫入 Markdown 報告與兩份 CSV（時數、Issue／PR）。欄位固定，方便把多人檔案接到同一張表 |

關掉視窗、按「離開」，或程式被關掉時，會把目前這段工時結束。若當機，下次開啟會用最後一次心跳（約 30 秒）當作離開時間。尚未用 GitHub 歸戶就匯出時，會提醒 `person_key` 還是本機使用者，PM 較難對人。

## 狀態列

「關閉控制台不會停止服務」。行程與 Log 寫在選定專案的 `.ai_project/`。要停服務請按「停止全部」或各列的停止。
