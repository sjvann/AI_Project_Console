# 畫面導覽

控制台是單一視窗。由上到下：標題列 → 專案列 → 工具列 → 摘要列 → 左右分頁 → 狀態列。

## 標題列

| 項目 | 作用 |
|------|------|
| 名稱與版本 | 目前安裝的控制台版號 |
| **設定** | 外觀、Agent、MCP、工具權限、專案問答。見 [設定](settings.md) |
| **檢查更新** | 查 GitHub Releases 是否有新版 |
| GitHub 帳號 | 已登入時顯示 `@帳號` |
| **登出 GitHub** | 登出 GitHub CLI。GitHub 管理的專案之後要重新登入 |
| **離開** | 關閉控制台視窗。工作區必須乾淨、且沒有未發布提交，否則不能離開 |

## 專案列

| 項目 | 作用 |
|------|------|
| 專案名稱／路徑 | 尚未選擇時會提示你選目錄 |
| **分支** | 目前 git 分支。點一下可切換或建立新分支 |
| **歷史專案** | 最近開過的目錄（最多 12 個仍存在的路徑） |
| **選擇專案目錄…** | 本機資料夾選擇 |
| **從 GitHub 開啟…** | clone 遠端倉後當作專案開啟 |
| **關閉專案** | 卸下目前工作區。工作區必須乾淨且已發布，否則不能關閉 |
| **啟動時還原上次專案** | 下次啟動自動載入 |
| **同時開啟 {後端}** | 載入專案時一併打開 Cursor（或其他你選的 Agent） |

## 工具列

| 按鈕 | 作用 |
|------|------|
| **啟動** | 依啟動順序啟動尚未在線的服務。有 `preStart` 的會先跑腳本，失敗則不啟動該服務 |
| **停止全部** | 停止此工作區控制台管到的服務 |
| **開啟前端** | 開預設前端網址，或「開啟全部 URL」 |
| **UAT 求救** | 填說明／貼截圖，交給 Agent。見 [卡住時怎麼辦](help.md) |
| **建置** | 編譯過期項目／全部服務／全部專案（含測試） |
| **GitHub** | 設定、切換分支、提交、同步、發布、Release。見 [GitHub](github.md) |
| **部署** | 發佈目標設定與狀態。見 [部署](deploy.md) |
| **環境體檢** | 跳出視窗：dotnet／git／gh／Agent／目前專案服務清單 |

建置「全部專案」會編譯目錄內全部 `.csproj`（含測試），可能要數分鐘，執行前會確認。

## 摘要列

一眼看值班狀態，不必翻分頁。

| 顯示 | 意思 |
|------|------|
| 就緒 N / M | 健康檢查通過的服務數／服務總數 |
| **需重編 N** | 點一下切到左側「專案」。黃色＝有過期項目 |
| **MCP 拒絕 N** | 點一下打開右側「MCP 審計」。Agent 呼叫被政策擋下時會增加 |
| **我的任務 N** | GitHub 專案登入後出現。點一下切到左側「任務」 |
| 堆疊正常／離線… | 值班一句話；與 MCP 工具 `duty_summary` 同一組數字 |
| 分支 · 未提交 · ↑↓ | git 狀態，可點擊切換分支。有未提交時可直接「提交…」 |
| 底部工作訊息 | 正在編譯、啟動等 |

## 左側：服務／專案／任務

連點「服務」「專案」分頁標題可全部展開或收合群組。

### 服務

每一列：線上／離線、名稱、連接埠、操作。

- **開啟** — 瀏覽器開該服務的 `openUrl`
- **啟動／重啟／停止** — 單一服務
- **隨 xxx** — 這個項目掛在另一個行程上（例如 Web 跟 API 同一 process），不要單獨啟動
- **失敗** — 滑鼠停上看啟動錯誤；右側 Log 有完整輸出

沒有服務時：放 `ai-project.json`，或確認 `launchSettings.json` 有 `applicationUrl`。

### 專案

每一列：專案名、類型／語言／上次編譯、狀態徽章、**編譯**。

| 徽章 | 意思 |
|------|------|
| 需重編 | 原始碼比輸出新。滑鼠停在列上看是哪個檔觸發 |
| 未建置 | 還沒編譯過 |
| 最新 | 控制台自己編譯成功且來源沒再改 |
| 編譯中 | 進行中（列會用主色標示） |
| 失敗 | 看右側「建置輸出」，可用編譯求救 |

勾選「只看需重編」可過濾。狀態不對時按「刷新」。`appsettings`、`data/*.json` 通常**不**應觸發需重編。

### 任務

登入 GitHub 後，顯示目前倉庫的開放 Issue。

- **我的任務** — 指派給你的項目。點標題開瀏覽器；按 **請 Agent 協助** 把 Issue 交給後端 Agent
- **未指派** — 沒有負責人的項目，預設可開合。按 **接受** 指派給自己，就會出現在上方

沒有 GitHub 遠端的本機目錄不會要求登入，這個分頁會提示尚未接上 GitHub。

## 右側：Log／建置／審計／問答

中間的分隔線可拖拉；連點還原左右各半。

### 服務 Log

選左側一個服務後顯示它的輸出。可搜尋、跟隨最新、清空顯示（不清實體檔）、開啟 `.ai_project/logs` 資料夾。線上服務異常時可用 **執行求救**。

### 建置輸出

顯示 `{已完成}/{預計}`。編譯失敗時 **編譯求救** 可用。報告也寫在 `.ai_project/build-reports/`。

### MCP 審計

Agent 透過 MCP 呼叫控制台的對帳單（成功或被拒）。尚無紀錄通常表示還沒接 MCP，不是故障。見 [MCP](../agent/mcp.md)。

### 專案問答

在控制台內用本機堆疊事實回答（預設接 Ollama）。**不會**外開 Cursor，也不會鎖住啟動／編譯。需先在設定填模型。見 [卡住時怎麼辦](help.md)。

## 狀態列

「關閉控制台不會停止服務」。行程與 Log 寫在選定專案的 `.ai_project/`。要停服務請按「停止全部」或各列的停止。
