# 設定

標題列「設定」打開偏好設定。分五個分頁。多數項目按「儲存」才寫入；「啟動時還原上次專案」「同時開啟 Agent」在主畫面勾選也會立刻記住。

設定檔位置（Windows）：`%LOCALAPPDATA%\AI_Project_Console\settings.json`。工時紀錄在同一資料夾的 `work-hours.json`（依專案切開時段；匯出的工時單是另外選資料夾寫入的 Markdown／CSV）。

## 一般

| 項目 | 作用 |
|------|------|
| 外觀 | 淺色／深色 |
| 啟動時還原上次專案 | 下次自動載入最後一個目錄 |
| 載入專案時開啟 Agent | 選好目錄後一併打開目前後端的工作區 |
| 發布前先跑本機測試 | 發布（push）或提交後再推之前，先跑一次完整測試。沒過就不推。詳細案例請在 IDE 跑 |
| 預設認證主機／種類 | 登入打哪一台 Git（`github.com` 或企業主機）。GitHub 相容才能開 Issue；其他種類可先設定 |
| **檢查更新** | 查 GitHub Releases 是否有新版。會先問要不要包含 RC／預發行。已安裝版會下載 setup 並啟動安裝程式；若最新 Release 沒有安裝包則改開 GitHub 頁 |
| **從檔案更新…** | 選本機 `*-setup.exe` 或 zip，略過下載直接安裝。從原始碼執行時不能覆蓋開發目錄 |
| 公司接收 API（申報目的地） | **規劃**可新增多家：顯示名＋該公司自架平台的 HTTPS Base URL。**現況**先填一個網址。工時儀表板「狀態圖」可對選定目的地申報；本機 `work-hours.json` 仍保留。未設定時控制台其餘功能照常 |

## Agent

控制台決定**何時**求救、提示裡帶什麼；後端只決定**在哪裡**跑。

1. 選後端（Cursor、Claude Code、Aider、Codex CLI、VS Code、Windsurf、自訂）。
2. 看偵測摘要：可用／找不到。
3. 自動偵測失敗時，填「CLI 路徑覆寫」。
4. 自訂後端再填命令與參數範本。可用變數：`{root}`、`{promptFile}`、`{prompt}`。

各後端差異見 [Agent 後端](../agent/backends.md)。求救用法見 [卡住時怎麼辦](help.md)。

## MCP

把「本控制台」和其他 MCP 寫進**目前專案**的 `.cursor/mcp.json`，讓 Agent 能查堆疊、編譯、啟停。清單只顯示專案檔，不含使用者全域 `~/.cursor/mcp.json`。

一般使用者最低限度：

1. 已開啟專案。
2. 在「已引用的 MCP」對「本控制台」按「加入」，或用下方下拉加入。
3. 重新載入 Cursor（或你的 IDE）。
4. 點摘要列「MCP 拒絕」打開審計視窗後會出現呼叫紀錄。

也可加入建議範本（GitHub、Context7）或「自訂」填命令／URL。細節與政策見 [MCP](../agent/mcp.md)。

「複製本控制台設定」可貼到使用者全域 mcp.json。「開啟 mcp.json」用系統編輯器開專案檔。

## 工具權限

限制 Agent **透過 MCP** 能做的事（與你在畫面按啟動無關）。

| 模式 | 效果 |
|------|------|
| 全部可用 | 已知工具都可呼叫；`stop_all` 預設仍需確認 |
| 唯讀 | 只能看狀態／Log／審計，不能編譯或啟停 |
| 自訂白名單 | 只暴露你加入的工具 |

單一工具可設允許／需確認／禁止。專案若已有 `.ai_project/mcp-policy.json`，會覆蓋這裡的同名欄位。可按「寫入專案政策範本」讓團隊共用。

## 專案問答

工具列「專案問答」用的端點。

| 欄位 | 建議 |
|------|------|
| Base URL | 本機 Ollama：`http://127.0.0.1:11434/v1` |
| API key | Ollama 可空白；雲端相容 API 必填 |
| 模型 | 例如 `llama3.2`，需已在 Ollama `pull` 過 |

用法見 [卡住時怎麼辦](help.md)。
