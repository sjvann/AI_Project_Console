# 進件（產品）

**現況：** 控制台需求工作台已出貨。畫面與關卡見 [需求工作台](../user/intake.md)。資料寫在目前工作區 `docs/product/intake.json`（以及 `intake-assets/`），那是**被管專案**的進件，不是本規格書。一筆進件開一張 GitHub Issue；必填標題與說明，指派與截圖可選。

**規劃：** 仲介需求精靈是給還沒有 Git 倉的需求公司發案用，不取代控制台進件。有倉之後才落到 Git。見 [仲介平台](marketplace.md) 與 [PRD](prd.md)。

## 現況關卡（控制台）

草稿 → 已發出 → 實作中 → 已驗收

缺標題或說明不能發出 Issue。驗收結案會關 GitHub Issue。暫停／收回會留言並留紀錄。審查、合併、發行、部署不在需求台操作。

## 規劃裡不要重複做的

控制台已經管本機進件與 GitHub Issue。公司工作區讀這些真相，不另做一套進件 UI。仲介精靈只負責成交前的範圍與資格。
