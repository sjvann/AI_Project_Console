# 進件（產品）

**現況：** 控制台需求工作台已出貨。畫面與關卡見 [需求工作台](../user/intake.md)。資料寫在目前工作區 `docs/product/intake.json`（以及 `design/`、`intake-assets/`），那是**被管專案**的進件，不是本規格書。

**規劃：** 仲介需求精靈是給還沒有 Git 倉的需求公司發案用，不取代控制台進件。有倉之後才落到 Git。見 [仲介平台](marketplace.md) 與 [PRD](prd.md)。

## 現況關卡（控制台）

草稿 → 設計就緒 → 已拆解 → 已發出 → 實作中 → 驗證中 → 可審查 → 已入主線 → 已發行 → 已部署 → 已驗收 → 已報帳

沒有驗收條件不能發出 Issue。介面新需求要草圖；介面設計變更要現況剪圖。CI 未綠不能合併。驗收要勾完條件。

## 規劃裡不要重複做的

控制台已經管本機進件與 GitHub Issue。公司工作區讀這些真相，不另做一套進件 UI。仲介精靈只負責成交前的範圍與資格。
