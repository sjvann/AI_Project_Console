# 預算費用

**規劃**（公司工作區 P2）。這是專案毛利視圖，不是總帳。不產生傳票、不報稅、不對銀行。人事成本來自已核准的公開回報入帳。

## 要解決的問題

軟體公司結案才發現這單賠了。收入在合約 PDF，人事在發薪與外包請款，工時在另一張表。需要每個專案隨時能回答：認列收入多少、人事成本多少、預估毛利多少。

## 收入

來源（人工維護，MVP 不接電子發票）：

- 合約總額按里程碑請款點拆分，或按專案期間直線攤提（專案建立時選一種）
- 已認列 vs 計劃：財務標記「已請款／已收款」（兩步可先合成一步「已認列」以減少填表）

T&M 合約：收入 = 已核准工時 × 對客戶費率（與對內人事成本分開）。對客戶費率只有 `finance`、`owner`、該專案 `pm`／`delivery` 可見。

## 人事成本

| 雇用類型 | MVP 成本口徑 |
|----------|----------------|
| 正職 | 月薪／當月工作日分攤到各專案，權重 = 該專案核准工時（無工時則用派工規劃小時） |
| 專案外包個人 | 核准工時 × 對內費率 |
| 承攬派駐 | 核准工時 × 對外包商費率 |

未核准工時不進入「實際成本」，可進「預估成本」並在戰情室用另一種色。

非人事成本（差旅、授權、雲）MVP 做成「其他費用」一筆列，不必做採購單。

## 毛利

- **預估毛利** = 計劃收入 − 預估人事 − 其他計劃
- **實際毛利** = 已認列收入 − 已入帳人事 − 其他實際
- **毛利率** = 毛利／對應收入；收入為 0 時顯示「—」不當 100%

門檻由公司設定（例如低於 25% 變黃、低於 10% 變紅）。戰情室讀同一組門檻。

## 月報 CSV

**專案損益表頭（固定，權威實作 `BudgetCsv.Header`）：**

| 欄位 | 語意 |
|------|------|
| `projectId` | 專案 Guid |
| `projectName` | 專案名 |
| `clientName` | 客戶名 |
| `plannedRevenue` / `actualRevenue` | 計劃／實際收入 |
| `plannedCost` / `actualCost` | 計劃／實際人事成本 |
| `otherPlanned` / `otherActual` | 其他費用 |
| `plannedMargin` / `actualMargin` | 毛利金額 |
| `plannedRate` / `actualRate` | 毛利率字串（收入為 0 為 `—`） |
| `currency` | 公司記帳幣 |

**正職／時計分攤明細表頭（`CostAllocationCsv.Header`）：**

| 欄位 | 語意 |
|------|------|
| `personId` / `displayName` | 人員 |
| `projectId` / `projectName` | 專案 |
| `hours` | 權重小時 |
| `costAmount` | 分攤成本 |
| `weightPercent` | 佔該人總分攤比重 |
| `source` | `核准工時`／`已送工時`／`派工規劃` |

## 關鍵畫面

- **專案損益卡：** 收入、人事、其他、毛利、率；計劃 vs 實際並排。
- **期間報表：** 選月，按專案或客戶匯出 CSV。
- **正職分攤明細：** 讓財務查「這個人這個月為什麼 30% 算在 A 專案」。

## 驗收條件（MVP）

- 固定價格專案能用里程碑認列收入，並看到人事實際來自薪資／工時核准。
- T&M 專案收入與對內成本用不同費率，工程師看不到對客戶費率。
- 匯出的月報欄位固定，可給既有會計系統再加工。
- 沒有工時的正職（例如純管理）可標「不參與專案分攤」，避免把成本塞進隨機專案。
