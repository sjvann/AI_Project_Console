# AI_Project · 給軟體公司的一頁紙

**本機交付指揮台，接上你們已有的 Agent。** **規劃（尚未出貨）：** 軟體工程仲介平台——有軟體需求的公司與工程師成交，抽仲介費；成交後用工作區管理、用控制台申報。加入免費，認證要強。

## 痛點（你們多半已經有工具）

工作單在系統裡，程式在工程師電腦，工時在試算表，外包在另一份合約。AI 會改碼，卻看不到需重編與就緒。專案毛利結案才知道。

## 現況可買（Windows 桌面控制台）

選專案 → 掃描服務與需重編 → 一鍵啟動 → GitHub 提交與 PR → 進件到驗收的關卡 → 工時從開啟專案起算並匯出對帳單。卡住把上下文交給本機 Cursor 等 Agent；MCP 讓 Agent 回查堆疊，動作可審計。**程式碼不上我們的雲。**

90 分鐘用**你們自己的倉**試完，見 [導入](../team/trial-90min.md)。

## 規劃中（尚未出貨，見產品規格）

**仲介平台（下一實作，我們營運的 SaaS）：** 需求公司（不限軟體業）用精靈發布專案；工程師應徵或受邀；成交產出合同與仲介應收；開工作區。

**成交後工作區：** 人員、派工、甘特、工時確認、薪資匯出、戰情室。工程師仍用控制台畫執行狀態並上傳，不到瀏覽器上班。自架工作區改後期。

細節：[產品規格](../product/README.md) · [仲介](../product/marketplace.md) · [PRD](../product/prd.md)。簡報不要把這段講成安裝包已有。

## 不是什麼

不取代 Jira 或 Cursor。不做汎用 ERP、報稅、勞健保申報。任務面以 GitHub 為準。

## 下一步

指定一位 Tech Lead、一位 PM。下載 [Releases](https://github.com/sjvann/AI_Project_Console/releases) 安裝包。走完導入後再談授權與規劃中的仲介／工作區時程。不要把規格書講成安裝包已有。
