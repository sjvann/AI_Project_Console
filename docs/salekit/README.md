# 銷售套件

給**外部軟體公司經營層與採購**的材料。一般使用者請走 [安裝與第一次使用](../user/getting-started.md)。產品與實作對齊請走 [產品規格](../product/README.md) 與 [PRD](../product/prd.md)。

## 現況可演示 vs 規格書中的規劃

| | 現況（可賣、可演示） | 規劃（規格書，尚未出貨） |
|--|----------------------|--------------------------|
| 產品 | Windows 本機控制台 | 仲介 SaaS（下一實作）＋獨立的公司工作區 |
| 能力 | 堆疊真相、開 GitHub Issue、工時對帳、Agent 閉環 | 會員認證、精靈發案、成交合同、抽成應收；工作區管人／專案／工時／毛利 |
| 簡報怎麼講 | 「今天就能用自己的倉跑 90 分鐘」 | 「仲介與工作區是採購後的規劃，不是現在安裝包裡的功能」 |

把規劃講成現況，會毀掉信任。投影片第 12 頁專門講路線圖，必須念標籤。

## 投影怎麼開

1. **寄給對方：** `docs/salekit/executive-pitch.pdf`。
2. **現場投影：** 瀏覽器開 `docs/salekit/executive-pitch.html`，`F11` 全螢幕。`→`／空白鍵下一頁，`←` 上一頁。
3. 圖表標「示意」：對照痛點，**不是**客戶實測。勿當保證成效。
4. 若改過 HTML、要重出 PDF：Edge 開 `executive-pitch.html?print=1`，再「列印 → 另存為 PDF」，或無頭 Edge `--print-to-pdf`。

建議聽眾：總經理、技術長、專案／交付主管、人資或財務。時間約 20 分鐘簡報 + 10 分鐘問答。若對方已決定要公司營運層，會後把 [產品規格](../product/README.md) 與 [PRD](../product/prd.md) 當作業說明，不要在簡報裡念完六個模組。

## 一句定位

AI_Project 控制台不是另一套雲端專案管理，也不是取代 Cursor 或 Copilot。它是坐在 **Git、GitHub、本機 Agent** 之上的 **Agentic 指揮台**。**規劃（尚未出貨）** 北極星是軟體工程仲介：需求公司與工程師成交後，用工作區管理、用控制台申報。見 [產品規格](../product/README.md)。
