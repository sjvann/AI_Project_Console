# 銷售套件

給**外部軟體公司經營層與採購**的材料。一般使用者請走 [安裝與第一次使用](../user/getting-started.md)。產品與實作對齊請走 [產品規格](../product/README.md) 與 [PRD](../product/prd.md)。

**與模啟的關係：** 本控制台是**本機交付優化工具**；產業應用 OS／模組上架與授權以 **模啟（ModuLaunch）** 為核心產品。簡報主軸若談產業底座，請以模啟為主、本台為可選加速器。見一頁紙開場段。

## 現況可演示 vs 規格書中的規劃

| | 現況（可賣、可演示） | 規劃（規格書，尚未出貨） |
|--|----------------------|--------------------------|
| 產品 | Windows 本機控制台（P1） | **下一實作**公司工作區（P2）；其後系統分析輔助（P3）；仲介（P4）為門檻產品 |
| 能力 | 堆疊真相、開 GitHub Issue、工時對帳、Agent 閉環 | 公開回報契約、專案貢獻、管人／派工／毛利；概念→Issue；門檻後才媒合／拆帳 |
| 簡報怎麼講 | 「今天就能用自己的倉跑 90 分鐘」 | 「工作區是下一刀；仲介不是現在安裝包，也不是下一上線」 |

把規劃講成現況，會毀掉信任。投影片講路線圖時必須念標籤。對齊 [產品規格](../product/README.md)。

## 投影怎麼開

1. **寄給對方：** `docs/salekit/executive-pitch.pdf`。
2. **現場投影：** 瀏覽器開 `docs/salekit/executive-pitch.html`，`F11` 全螢幕。`→`／空白鍵下一頁，`←` 上一頁。
3. 圖表標「示意」：對照痛點，**不是**客戶實測。勿當保證成效。
4. 若改過 HTML、要重出 PDF：Edge 開 `executive-pitch.html?print=1`，再「列印 → 另存為 PDF」，或無頭 Edge `--print-to-pdf`。

建議聽眾：總經理、技術長、專案／交付主管、人資或財務。時間約 20 分鐘簡報 + 10 分鐘問答。若對方已決定要公司營運層，會後把 [產品規格](../product/README.md) 與 [PRD](../product/prd.md) 當作業說明，不要在簡報裡念完六個模組。

## 一句定位

AI_Project 控制台不是另一套雲端專案管理，也不是取代 Cursor 或 Copilot。它是坐在 **Git、GitHub、本機 Agent** 之上的 **Agentic 指揮台**，給工程師跨公司、跨專案做工與申報。**規劃（尚未出貨）** 下一刀是公司工作區＋公開回報契約；系統分析輔助在其後；仲介僅在分析能力驗證後才開。見 [產品規格](../product/README.md) · [一頁紙](one-pager.md)。
