# 採購 FAQ

簡短回答。細節連到規格或使用文件。

## 原始碼公開是不是開源？能商用改裝嗎？

**不是開源。** 倉庫公開可見，授權是保留一切權利。官方安裝包可供評估或你自己內部使用控制台；把原始碼當產品再發布、代管或 OEM 需要另外書面授權。公司工作區與仲介程式是規劃／示範，未授權正式營運。見 [版權與授權](../legal/copyright.md) 與倉根 [LICENSE](https://github.com/sjvann/AI_Project_Console/blob/main/LICENSE)。

## 資安：程式碼會到你們的雲嗎？

不會。控制台是本機桌面，不把原始碼上傳到本產品自己的雲。Agent 是你們選的本機後端。MCP 有審計。規劃中的仲介與工作區由我們營運時，上傳的仍是工時時段與狀態圖，不是原始碼。見 [技術架構](../product/architecture.md)。

## 我們已經有 Cursor／Copilot

繼續用。本產品不取代 IDE。它讓 Agent 接到需重編、就緒與 Log，並用 MCP 驗證。見 [Agent 後端](../agent/backends.md)。

## 我們已經有 Jira

工作單可以留在原處。本產品管本機真相、關卡與工時對帳。任務面**目前**接 GitHub Issue。Jira 雙向同步列在路線圖後續，不是 MVP。見 [願景](../product/vision.md)。

## 只會 .NET 嗎？

正式安裝包是 Windows x64、macOS（arm64／x64）、Linux（x64／arm64）。被管理的 .NET 專案仍需本機 SDK。多倉用工作區清單。控制台本身是 .NET 10。公司平台規劃同樣是 .NET 10 Blazor Web App。Mac 包尚未 Apple 公證，第一次請右鍵打開。

## 外包怎麼管？現在有嗎？

**現況**只有 GitHub 帳號與工時歸戶，沒有外包商主檔與費率隔離。**規劃**才有正職／個人外包／承攬派駐與窗口權限。見 [人員與外包](../product/modules/people.md)。不要承諾現在就能管承攬合約。

## 戰情室、甘特、薪資何時有？

寫在 [路線圖](../product/roadmap.md) 與 [PRD](../product/prd.md)，**尚未出貨**。下一實作是仲介成交閉環；戰情室屬公司工作區（獨立機制）。今天能演示的是控制台。不要寫進現況安裝包的驗收。

## 會不會被鎖死？

真相在 Git 與遠端倉。離開仍帶走 Issue、PR、文件與程式。Agent 後端可換。工作區資料在租戶庫（我們營運或客戶自架，同一安裝產物）。

## 工時會不會變成監視？

工時從**開啟專案**起算，不是鍵盤側錄。滿 8／10 小時是給本人看的提示。公司平台核准流是為了發薪與毛利，規格要求人為修改留審計。見 [畫面導覽：工時](../user/interface.md#工時儀表板)。

## 要不要買雲端授權？

控制台依約定授權出安裝包。規劃中的仲介是我們營運的 SaaS（會員、成交、抽成）。工作區是獨立安裝產物，我們主機與自架用同一通道。原始碼仍不上雲。見 [願景](../product/vision.md)、[技術架構](../product/architecture.md)。
